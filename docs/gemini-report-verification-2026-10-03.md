# Gemini Report.md 검증

검토 대상은 저장소 루트 `Report.md`이며 원문은 수정하지 않았다. 기준 코드는 `31ebd19` 이후 작업 트리다. 보고서의 “100% 확실”은 결론으로 받아들이지 않고 재현, 코드 확인, 미측정을 구분했다.

## 검증 진행

- 수정 전 9개 재현 테스트가 실패했다: 앱 메시지/CSP/이름/버전/PID 5개, 설치기 버전/제거 2개, 릴레이/파일 복구 2개.
- 새 검증은 TEMP 디렉터리, 설치기 전용 임시 레지스트리, 루프백 소켓, 보이지 않는 WebView2에서 수행한다. 공개망 연결 기존 회귀 테스트는 별도로 남아 있다.
- 새 테스트 이름에는 `report NN:`을 넣었다. `DESKCARDS_TEST_FILTER='report '`로 앱/설치기 각각 실행할 수 있다. 설치기에도 같은 필터를 추가했다.
- 수정 후 보고서 관련 테스트는 앱 17개·설치기 4개, 총 21개 모두 통과했다. 앱 Debug/Release 및 설치기 테스트 빌드는 경고·오류 0개다.
- 사용자 승인 후 안내 창을 켠 상태로 전체 회귀를 실행했다. 앱 **81개 통과/실패 0개**, 설치기 **63개 통과/실패 0개**, 두 프로세스 모두 exit 0이다. 새 보고서 테스트 21개를 포함한다.
- 앱·설치기 안내 창을 각각 PrintWindow(flag 2)로 캡처해 문구, 둥근 모서리, 진행 표시, 검사 수, 푸터 배치를 확인했다. 캡처 파일은 `%TEMP%/DeskCards-test-status-app.png`, `%TEMP%/DeskCards-test-status-setup.png`다. 실행 로그는 `%TEMP%/DeskCards-report-full-app.log`, `%TEMP%/DeskCards-report-full-setup.log`에 남겼다.
- 앱 종료 시 기존 Chromium `Failed to unregister class Chrome_WidgetWin_0. Error = 1412` 진단 한 줄이 남았다. 테스트 실패나 비정상 종료는 없었으며 이 진단 자체를 해결한 것으로 간주하지 않는다.
- 테스트 실행기는 시작하자마자 Windows Shell의 `MinimizeAll`로 바탕화면을 보이고 화면 중앙에 공통 Windows 11 스타일 진행 창을 띄운다. 안내 창은 별도 STA에서 진행 표시·완료 수·경과 시간을 갱신하며 종료 시 닫힌다. 필터 실행도 기본 동작은 동일하다. 화면 없는 진단에만 `DESKCARDS_TEST_HEADLESS=1`을 명시한다. `DESKCARDS_TEST_STATUS_SNAPSHOT`에 PNG 경로를 지정하면 안내 창만 PrintWindow(flag 2)로 저장한다.
- 이 PC에 .NET Framework 4.8 targeting pack이 없어 설치기는 `-p:AutomaticallyUseReferenceAssemblyPackages=true`로 NuGet 참조 어셈블리를 사용해 빌드한다. 시스템 SDK 설치는 하지 않았다.

## 구현상 주의와 출처

- CSP 변경 후 `onclick` 같은 속성 핸들러는 허용되지 않는다. 승인된 `<script>` 안에서 `addEventListener`를 사용해야 한다. 저장소 내 기존 예제에는 해당 속성 핸들러가 없었다.
- 해시는 동적 코드 문자열의 직접 실행을 막지만, 승인된 코드 자체의 모든 악의적 행동을 증명하거나 차단하는 장치는 아니다. nonce만 주입하는 방식은 승인된 스크립트가 nonce를 재사용할 수 있어 이 위협 모델의 대안으로 채택하지 않았다.
- [W3C CSP3](https://www.w3.org/TR/CSP/): 해시/nonce/unsafe-inline 실행 조건.
- [Chromium 제한 포트 구현](https://chromium.googlesource.com/chromium/src/+/master/net/base/port_util.cc): SSH·SMTP 등 포트 제한. 실제 설치된 WebView2에서도 별도로 확인했다.
- [AngleSharp](https://www.nuget.org/packages/AngleSharp): HTML5 파서. 버전 1.8.3 고정, 네트워크 로더·JS 실행기는 사용하지 않는다.

원문 부록의 HwndSource 훅 해제·Config 동시성·임시 파일 고갈 판정은 이번 12개 항목 테스트의 검증 범위에 포함하지 않았다.
