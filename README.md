# Desk Cards

Windows 11 시작 메뉴의 **모든 앱 → 보기: 범주** 폴더 모양을 바탕화면으로 옮긴 앱입니다.
바로가기를 카드 하나에 묶어 두고, 누르면 시작 메뉴처럼 펼쳐져서 안의 앱을 고를 수 있습니다.

Fences처럼 바탕화면 배경에 칸을 그어 두는 방식이 아니라, **작은 폴더 카드**가 바탕화면 위에 떠 있는 방식입니다.

---

## 설치

1. [DeskCards-Setup.exe](https://github.com/hhsshoo12/desk-cards/releases/latest/download/DeskCards-Setup.exe)를 받습니다. **설치할 때 인터넷 연결이 필요합니다.**
2. 실행해서 안내에 따라 [다음]을 누르면 됩니다. 관리자 권한은 필요 없고, .NET을 따로 설치하지 않아도 됩니다.
   - 설치 위치: `%LOCALAPPDATA%\Programs\Desk Cards` (고정)
   - 추가 작업: 시작 메뉴 바로가기, 바탕화면 바로가기, Windows 시작 시 자동 실행
3. 새 버전은 앱이 스스로 받아 둡니다([정보](#정보) 참고). 설치기를 다시 실행해도 최신 버전으로 업데이트됩니다. 만들어 둔 그룹과 카드 위치·크기는 그대로 남습니다.

> Windows SmartScreen이 "Windows의 PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르세요. 서명되지 않은 개인 프로젝트라 처음 한 번 뜰 수 있습니다.

### 제거

**설정 → 앱 → 설치된 앱**에서 "Desk Cards"를 찾아 제거합니다.
그룹 폴더(`내 사용자 폴더\DeskCards`)와 그 안의 바로가기는 지우지 않으니, 필요 없으면 직접 지우세요.

---

## 시작하기

1. 설치가 끝나면 Desk Cards가 실행됩니다.
2. 바탕화면 오른쪽 위에 빈 카드 **새 그룹**이 하나 생깁니다.
3. 바탕화면 아이콘이나 시작 메뉴의 앱을 카드 위로 끌어다 놓으면 카드에 들어갑니다.
4. 작업 표시줄 오른쪽 트레이에 2×2 네모 아이콘이 생깁니다. **더블클릭하면 설정**이 열립니다.
   (이미 실행 중일 때 시작 메뉴의 Desk Cards를 다시 눌러도 설정이 열립니다.)

> 바탕화면 보기(Win + D)를 눌러도 카드는 사라지지 않고, 항상 다른 창들 뒤(바탕화면 바로 위)에 머뭅니다.

## 카드 쓰기

| 하고 싶은 것 | 방법 |
|---|---|
| 앱 실행 | 카드 안의 아이콘 클릭 |
| 카드 펼치기 | 더보기 칸(작은 아이콘 4개가 모인 마지막 칸) 클릭, 또는 우클릭 → 펼치기 |
| 앱을 카드에 넣기 | 파일·바로가기를 카드(또는 펼친 창) 위로 끌어다 놓기 |
| 앱을 카드에서 꺼내기 | 아이콘을 카드 밖으로 끌어내기 |
| 카드 안 순서 바꾸기 | 펼친 창에서 아이콘을 원하는 칸으로 끌어 놓기 (위·아래 끝에 대면 페이지가 넘어가요) |
| 앱 메뉴 (관리자 권한 실행, 다른 그룹으로 이동, 휴지통 등) | 카드나 펼친 창의 아이콘에서 마우스 오른쪽 클릭 |
| 카드 메뉴 | 카드의 아이콘이 아닌 곳에서 마우스 오른쪽 클릭 |

### 끌어다 놓으면 어떻게 되나요?

- **바탕화면 아이콘, 바로가기(.lnk / .url), 다른 카드에 있던 항목**은 그대로 **옮겨집니다**. (바탕화면에서는 사라지고 카드로 들어갑니다.)
- **그 밖의 파일**(예: `Program Files` 안의 실행 파일)은 원본은 그대로 두고 카드에 **바로가기를 새로 만듭니다**.

## 펼친 창

카드를 누르면 시작 메뉴 폴더처럼 가운데에 제목이 있고 앱이 4×3으로 놓인 창이 뜹니다.

- 앱이 12개를 넘으면 **마우스 휠**이나 **↑ ↓ / PageUp PageDown**으로 페이지를 넘깁니다. 오른쪽 점을 눌러도 됩니다.
- **제목을 누르면** 그룹 이름을 바꿀 수 있습니다. (Enter로 확정)
- 앱에서 **오른쪽 클릭**하면 이런 메뉴가 나옵니다.
  - 열기
  - 관리자 권한으로 실행
  - 파일 위치 열기
  - 다른 그룹으로 이동
  - 바탕화면으로 꺼내기
  - 휴지통으로 이동
- 창 바깥을 누르거나 Esc를 누르면 닫힙니다.

## 설정

트레이 아이콘을 더블클릭하거나, 펼친 창 오른쪽 위 ⚙ 또는 카드 우클릭 메뉴의 **설정**을 누르면
Windows 설정 앱처럼 생긴 설정 창이 열립니다. 왼쪽 메뉴는 **카드 / 일반 / 정보**입니다.

### 카드

- **카드 편집**: 화면 위쪽에 편집 막대가 뜹니다. (아래 [카드 편집](#카드-편집) 참고)
- **새 그룹**: 빈 카드를 하나 만듭니다.
- **그룹 목록**: 그룹을 누르면 그 카드만의 설정이 나옵니다.
  - **이름**: 그룹 폴더 이름도 같이 바뀝니다.
  - **크기**: 카드 크기를 %로 보여 줍니다. `−` `+`는 5%씩 바뀌고, 숫자를 눌러 직접 입력할 수도 있습니다.
  - **미리보기 칸 (가로 / 세로)**: 카드 안에 보이는 아이콘 칸 수를 1~8칸까지 정합니다. 칸 수에 따라 카드 모양이 바뀝니다. (예: 4×2면 옆으로 긴 카드)
  - **폴더 열기**: 탐색기에서 이 그룹의 실제 폴더를 엽니다.
  - **이 그룹 삭제**: 안에 있던 항목은 바탕화면으로 옮겨진 뒤 그룹이 지워집니다. 파일이 사라지지 않습니다.

### 카드 바

앱을 쓰는 중에도 카드를 꺼내 쓰는 줄입니다. 조합키(기본 Ctrl + Alt + D. 설정에서 [조합키 만들기]를 누르고 보조키와 일반 키 하나를 함께 눌러 Alt + S처럼 바꿀 수 있고, Windows 단축키로 등록돼 다른 앱에는 전달되지 않습니다)를 누른 채 고른 화면 가장자리(기본 오른쪽)에 마우스를 대고 있으면 커서 둘레의 게이지가 한 바퀴 돌고 바가 미끄러져 나옵니다. 바 밖으로 마우스를 옮기면 들어갑니다. 가장자리는 한 곳만 고르고 작업 표시줄이 있는 쪽은 고를 수 없으며, 대고 있을 시간(즉시~2초)과 바 두께(화면의 10~33%)를 정할 수 있습니다. 전체 화면 게임·영상 위에서는 열리지 않습니다.

### 일반

- **Windows 시작 시 실행**: 켜 두면 로그인할 때 자동으로 실행됩니다.
- **Windows 배율 따라가기**
  - 켜 두면 Windows 디스플레이 배율(125%, 150% 등)을 바꿀 때 카드도 같은 비율로 커지고 작아집니다.
  - 꺼 두면 배율을 바꿔도 카드 크기가 그대로입니다.
  - 켜고 끄는 순간에는 카드 크기가 바뀌지 않고, 어느 쪽이든 크기 조절은 자유롭게 할 수 있습니다.
- **안내선 · 자동 맞춤**: 아래 보라색 안내선을 켜고 끕니다.
- **더보기에 올려 두면 펼치기**: 카드 마지막 칸(작은 아이콘 4개가 모인 더보기 칸)에 마우스를 잠시 올려 두면 누르지 않아도 펼쳐지고, 펼쳐진 창 밖으로 마우스를 옮기면 바로 접힙니다. 기다리는 시간은 즉시·0.1~1초 중에서 고르고, 1초에서 더 늘리면 꺼집니다. [−] [+] 칸에 마우스를 올리고 휠을 굴려도 바뀝니다.
- **자동 업데이트**: 켜 두면(기본) 새 버전을 미리 받아 두었다가, 다음에 앱을 켤 때(보통 PC를 다시 켤 때) 새 버전으로 엽니다.
- **그룹 폴더**: 모든 그룹 폴더가 있는 곳을 엽니다.

### 정보

버전, GitHub 주소, 설정 파일이 있는 폴더를 보여 줍니다.

버전 오른쪽 버튼으로 업데이트할 수 있습니다.

| 버튼 | 뜻 |
|---|---|
| 최신 (흰색) | 지금이 최신 버전입니다. |
| **업데이트** (파란색) | 새 버전이 있습니다. "현재 버전 → 최신 버전"이 함께 보이고, 누르면 받는 동안 진행 막대가 나옵니다. |
| **앱 재시작** (파란색) | 새 버전을 받아 두었습니다. 누르면 바로 새 버전으로 다시 켜집니다. 누르지 않아도 다음에 앱을 켤 때 바뀝니다. |

## 카드 편집

설정의 **카드 편집**, 카드 우클릭 메뉴의 **카드 편집**, 트레이 메뉴 중 하나로 시작합니다.
Windows 캡처 도구처럼 화면 위쪽 가운데에 막대가 뜨고, 모든 카드를 한꺼번에 손볼 수 있습니다.

- 편집을 시작하면 **바탕화면 보기**처럼 다른 창이 모두 내려가고, 작업 표시줄을 뺀 화면이 어두워집니다. 카드와 막대만 밝게 보입니다.
  (편집 전에 열려 있던 설정 창만 편집이 끝나면 다시 나타납니다.)

- 카드를 **끌어서 옮기고**, 오른쪽 아래 모서리를 끌어서 **크기**를 바꿉니다. (모양은 그대로 두고 크기만 바뀝니다.)
- 카드를 **누르면 골라집니다**(파랗게 빛남). 막대의 버튼은 고른 카드에 적용됩니다.
- 바탕화면(어두운 곳)을 누르면 고른 카드만 풀리고 편집은 계속됩니다. 편집은 **[✓ 완료]**를 눌러야 끝납니다.

| 막대 버튼 | 하는 일 |
|---|---|
| 새 그룹 | 빈 카드를 만들고 바로 고릅니다 |
| 안내선 | 보라색 안내선·자동 맞춤 켜고 끄기 (켜져 있으면 아래 파란 줄) |
| 이름 바꾸기 | 고른 카드의 이름 바꾸기 |
| 칸 수 ▾ | 1×1 ~ 4×4 중에서 미리보기 칸 모양 고르기 |
| 삭제 | 고른 카드 지우기 (항목은 바탕화면으로) |
| ⚙ | 설정 열기 |
| ✓ 완료 | 편집 끝내기 (파란 버튼) |

막대가 선택된 상태에서 쓸 수 있는 키:

- **Esc**: 편집 끝내기 ([완료]와 같음)
- **Delete**: 고른 카드 삭제
- **화살표**: 고른 카드를 1픽셀씩 옮기기 (**Shift**를 누르면 10픽셀씩)

## 옮길 때 나오는 보라색 안내선

카드를 옮기거나 크기를 바꿀 때 Canva·Figma처럼 **보라색 안내선**이 나옵니다.

- 다른 카드의 끝선이나 가운데, 화면 가운데와 줄이 맞으면 카드가 살짝 붙고 선이 보입니다.
- 붙는 게 방해되면 **Alt를 누른 채** 끌면 됩니다. 아예 끄려면 편집 막대의 안내선 버튼이나 설정 → 일반에서 끕니다.
- 카드는 작업 표시줄을 뺀 화면 밖으로 나가지 않습니다.

## 자주 묻는 것

**카드 안의 앱은 실제로 어디에 있나요?**
그룹 하나는 `내 사용자 폴더\DeskCards\그룹 이름` 폴더 하나입니다.
탐색기에서 이 폴더에 파일을 넣거나 폴더를 새로 만들어도 카드에 바로 반영됩니다.

**앱을 지우면 카드 안의 바로가기도 없어지나요?**
아니요. 앱을 종료하거나 지워도 위 폴더와 그 안의 파일은 그대로 남습니다.

**카드 위치나 크기는 어디에 저장되나요?**
`%APPDATA%\DeskCards\config.json`에 저장됩니다. 이 파일을 지우면 위치와 크기가 처음 상태로 돌아갑니다. 그룹과 앱은 그대로입니다.

**예전 이름(DeskFolders)으로 쓰던 그룹은요?**
처음 실행할 때 `DeskFolders` 폴더를 `DeskCards`로 자동으로 옮깁니다. 그룹과 설정은 그대로 이어집니다.

**탐색기가 재시작되면요?**
카드가 잠깐 사라졌다가 몇 초 안에 다시 나타납니다.

## 요구 사항

- Windows 11 22H2 이상 권장 (그 이전 버전에서도 동작하지만 펼친 창의 반투명 효과는 나오지 않습니다)

## 직접 빌드하기

[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)가 필요합니다.

```
dotnet build src/DeskCards -c Release
```

실행 파일은 `src/DeskCards/bin/Release/net10.0-windows/DeskCards.exe`에 생깁니다.

설치 파일까지 만들려면 .NET Framework 4.8 Developer Pack이 더 필요합니다. 설치기는 `net48` WPF이고 외부 NuGet 패키지를 사용하지 않습니다. 앱은 .NET 10 self-contained를 유지합니다.

```
pwsh -File installer/build.ps1
```

`installer/dist/app/`에 `DeskCards-win-x64.zip`과 `.sha256`, `installer/dist/installer/`에 `DeskCards-Setup.exe`가 생깁니다.
`-App` 또는 `-Installer`를 붙이면 해당 구성만 빌드합니다. 버전은 각 프로젝트의 `<Version>`에서 읽습니다.

앱은 `app-vX.Y.Z` 태그로 먼저 올리고(`--latest=false`), 설치기는 `installer-vX.Y.Z` 태그로 **Latest**로 올립니다.
첫 배포는 둘 다 `0.2.0`입니다. 기존 `v0.1.0`에는 새 형식의 파일이 없으므로 이 배포 전에는 웹 설치기로 앱을 받을 수 없습니다.
빌드 스크립트는 업로드 명령을 출력만 합니다. 앱과 설치기의 버전은 이후 따로 올릴 수 있으며 설치기는 자신의 버전 이상인 앱만 받습니다.

## 회귀 테스트

```powershell
dotnet run --project tests/DeskCards.RegressionTests -c Release --no-launch-profile
dotnet run --project tests/DeskCards.Setup.Tests -c Release --no-launch-profile
```

테스트는 임시 폴더를 사용하며 기존 그룹·설정은 변경하지 않습니다. C# 테스트 중에는 테스트 창이 잠깐 나타납니다.
설치기 테스트는 `%TEMP%\DeskCards-Setup-Tests-<GUID>`와 `HKCU\Software\DeskCards-Setup-Tests\<GUID>`만 사용하고 종료 시 정리합니다.
다운로드와 앱 프로세스 제어는 테스트 대역을 사용합니다. 실제 설치·업데이트·제거는 수동 확인 대상입니다.
점검 결과와 검증 범위는 [DEBUGGING.md](DEBUGGING.md)에 정리되어 있습니다.
