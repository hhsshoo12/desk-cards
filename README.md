# DeskFolders

Windows 11 시작 메뉴의 "범주" 보기처럼, 바탕화면에 2×2 미리보기 카드로 바로가기를 묶어 두는 앱.

- 그룹 하나 = `%USERPROFILE%\DeskFolders\<그룹 이름>` 실제 폴더 하나. 탐색기에서 폴더를 만들거나 파일을 넣어도 바로 반영된다.
- 카드 위치는 `%APPDATA%\DeskFolders\config.json`에 저장.
- 카드: 아이콘 클릭 = 실행, 빈 곳/`+N` 칸 클릭 = 펼치기, 끌기 = 카드 이동(8px 격자), 아이콘 끌기 = 밖으로 꺼내기, 우클릭 = 메뉴.
- 드롭 규칙: `.lnk/.url`, 바탕화면 항목, 다른 그룹 항목은 **이동**. 그 외(예: Program Files의 exe)는 원본을 두고 **바로가기 생성**.
- 펼침 창: 제목 클릭으로 이름 바꾸기, 항목 우클릭으로 다른 그룹 이동/바탕화면으로 꺼내기/휴지통.
- 트레이 아이콘: 새 그룹, 그룹 폴더 열기, Windows 시작 시 실행, 종료.

## 빌드

```
dotnet build src/DeskFolders -c Release
```
